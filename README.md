# Gym website

A static, responsive gym landing page. Open `index.html` directly in a modern browser; there is no build step. The “Same room. Same grind. Your pace.” section pins for a 220vh scroll sequence and scatters eight training photos around the headline. It includes a smaller mobile scatter radius, pointer parallax, hover color treatment, and reduced-motion handling. The location form searches for nearby gyms in Google Maps.

## Files

- `index.html` — page structure and image cards
- `styles.css` — site styling and responsive scatter layout
- `script.js` — navigation, timeline, location search, reveals, and GSAP scroll sequence

The photos, Google font, GSAP, and ScrollTrigger load from external CDNs, so a network connection is required. The photos are illustrative hosted images. Confirm image licenses before commercial use.
